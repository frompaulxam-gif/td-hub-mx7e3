# TDG Hub

Internal QC and planning tool for Paul (Head of Content, Triple Down Group). One person, daily, on a MacBook (chromeless app window) and phone. He reviews each week's Instagram content for two venue clients, approves or requests changes, ticks off his own to-dos, and adjusts rendered graphics.

- register: product
- stack: vanilla HTML/CSS/JS single page + python stdlib server (no build step, no frameworks)
- surfaces: compact week board (day rows, grid|story), expanded editorial day review (reference vs this-week, captions, comment threads, tickable checklists), calendar, graphic layout editor, photo picker
- venues: Merchants Yard (warm, outdoor, brown ink + yard green accent) and Moonshine (speakeasy near-black + oxblood red accent); the app reskins per venue but structure never changes
- data: week.json files in each venue folder, written back live by the server
- quality bar: feels like a private studio tool, not a generated dashboard; the tool disappears into the task
- hard rule: no em dashes anywhere in UI copy
